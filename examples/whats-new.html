Usero What's New Smoke Test

Mounts the widget with whatsNew: true. By default it points at a local Usero dev server on http://localhost:5271. No dev server? Run the stub and add ?baseUrl=http://localhost:5273 to this page's URL:

node examples/whats-new-stub-server.mjs

Then check:

  1. A red unread dot appears on the launcher (first visit: everything unread).
  2. Open the panel: a Feedback / What's new tab header is present, with an unread count badge.
  3. Switch to What's new: a pinned "Shipped for you" section (the stub returns one for the identified email) sits above the entry list; titles with URLs open in a new tab.
  4. Close and reopen: the dot and badge are gone (opening the view marked all seen).
  5. Click the button below to clear the last-seen key and reload; the dot returns.
